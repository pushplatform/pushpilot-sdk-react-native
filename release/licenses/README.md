# Release licensing

On 2026-10-11 the owner selected MIT for Push Platform's own Android and iOS
SDK code. `android.LICENSE` and `ios.LICENSE` carry that license and the
Push Platform Team copyright notice. The release staging process copies
them into `native/android/LICENSE` and `native/ios/LICENSE`.

The pinned native repositories do not contain their own LICENSE files.
The Android README's old Apache-2.0 badge is superseded for our own code
by this owner decision; external dependencies keep their original licenses.

`Apache-2.0.txt` is the unmodified license text downloaded from
https://www.apache.org/licenses/LICENSE-2.0.txt for third-party dependencies.
See `../THIRD_PARTY_NOTICES.md` for attribution and dependency scope.
