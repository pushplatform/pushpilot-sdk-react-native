# npm-пакет 2.0.5

```sh
npm install https://github.com/pushplatform/pushpilot-sdk-react-native/releases/download/v2.0.5/pushplatform-react-native-2.0.5.tgz
```

Пакет содержит JavaScript/TypeScript API, RN bridge, Expo plugin, Android SDK 2.0.4 и iOS SDK 2.0.3.
После обновления пересоберите нативное приложение. Установка описана в
[INSTALLATION.md](INSTALLATION.md), выпуск — в [RELEASING.md](RELEASING.md).
